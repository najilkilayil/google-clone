# 🔍 Google Homepage Clone

A clean and modern Google homepage clone created using only **HTML and CSS**

---

## ✨ Features
- Google styled homepage UI
- Top navigation bar
- Search bar with icons
- Ai mode button
- Footer navigation section
- Hover effects
- Custom Google font
- Google-like color styling

---

## 🛠️ Built With
- HTML
- CSS
- Google Fonts
- Icons8 Icons
